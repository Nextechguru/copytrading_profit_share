⚙ GitHub Setup

Your data will be saved in a data.json file inside your GitHub repo.
All team members using the same repo will share the same data.

How to get a GitHub Token:
1. Go to github.com → Login
2. Top-right avatar → Settings
3. Left sidebar → Developer settings → Personal access tokens → Tokens (classic)
4. Click Generate new token (classic)
5. Give it a name (e.g. bis-tracker), tick only repo checkbox
6. Click Generate → Copy the token (starts with ghp_)
Use local storage only (data won't sync across devices)
